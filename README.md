# 3L Dataset · Low Light Level

Website of the **3L Dataset**, an aligned, physically realistic low-light dataset
for Low-Light Image Enhancement (LLIE), developed by [3L-OPTRONICS](https://3l-optronics.com).

🔗 **Website:** https://Maurgene-ghezal-3l.github.io/3L-Dataset/
📄 **Paper:** coming soon (arXiv)
🤗 **Data:** Maumauuu/3L-Dataset (Hugging Face)

## About

Each scene is captured on a calibrated bench at one reference level and five
night levels (n0 to n5), with pixel-perfect alignment across levels.

## Repository

This repository only contains the static website (HTML, CSS, JS).
The dataset itself is distributed separately.
